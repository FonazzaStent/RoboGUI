RoboGUI 1.2.1
SymbolForm
The program is a GUI shell for Windows terminal program Robocopy, set
with the /S parameter fixed, to backup only newer files from one
directory to another. This means if you are working on files in a
directory and keep a backup on another drive or in another position on
the same drive, the program will backup only the files you have been
working on, which have a more recent date compared to unmodified files.
Robocopy is a terminal (command line) command in Windows and this program
is a simple GUI shell, composed of two file panes to select origin and
destination folders and a button to launch the Robocopy command.

- Select drive letters for source and destination
- Browse folders in the left pane to select source
- Browse folders in the right pane to select destination
- If your folder is a network location insert it in the field near
  the drive letter
- Click on Robocopy to backup the source folder to the destination folder

A copy of the old version, using file selectors, is included.
